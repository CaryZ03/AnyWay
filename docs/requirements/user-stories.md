# 用户故事文档

## 一、智能体管理模块

### P0 - US-001：创建智能体

- **描述**：用户登录系统后创建新智能体，填写相关信息提交，系统保存并返回信息，用于使用AI助手完成特定任务。
- **验收标准**：
  - 给定：用户已登录系统。
  - 当：用户填写智能体名称、描述、提示词等信息并提交。
  - 那么：系统创建智能体并保存到数据库，返回创建成功的智能体信息。
- **依赖关系**：无
- **估算工作量**：5 故事点

### P0 - US-002：查看智能体列表

- **描述**：登录用户访问智能体列表页面，查看自己创建的所有智能体信息，便于管理和选择使用。
- **验收标准**：
  - 给定：用户已登录系统。
  - 当：用户访问智能体列表页面。
  - 那么：系统显示该用户创建的所有智能体，包括名称、描述、状态等信息。
- **依赖关系**：依赖于 US-001 创建智能体，只有先创建智能体，才能查看列表。
- **估算工作量**：2 故事点

### P1 - US-003：编辑智能体

- **描述**：用户登录后对已创建的智能体信息进行修改并保存，更新智能体配置和提示词。
- **验收标准**：
  - 给定：用户已登录系统且存在要编辑的智能体。
  - 当：用户修改智能体信息并保存。
  - 那么：系统更新智能体信息，更新修改时间。
- **依赖关系**：依赖于 US-001 创建智能体，需要先有创建的智能体才能进行编辑。
- **估算工作量**：3 故事点

### P0 - US-004：测试智能体

- **描述**：用户创建智能体后，输入测试问题提交，系统调用AI模型生成回答返回，验证配置是否正确。
- **验收标准**：
  - 给定：用户已创建智能体。
  - 当：用户输入测试问题并提交。
  - 那么：系统调用AI模型生成回答并返回给用户。
- **依赖关系**：依赖于 US-001 创建智能体，创建后才能进行测试。
- **估算工作量**：3 故事点

### P1 - US-014：删除智能体

- **描述**：登录用户在智能体列表中选择要删除的智能体，确认删除操作后，系统将该智能体从数据库中移除，释放系统资源。
- **验收标准**：
  - 给定：用户已登录系统且存在要删除的智能体。
  - 当：用户在智能体列表中选择智能体，点击删除按钮并确认删除操作。
  - 那么：系统验证用户权限，若有权限则将该智能体从数据库中删除，同时在智能体列表页面中刷新显示，移除已删除的智能体。
- **依赖关系**：依赖于 US-001 创建智能体和 US-002 查看智能体列表，先有创建和查看操作，才能进行删除。
- **估算工作量**：3 故事点

## 二、知识库管理模块

### P1 - US-005：创建知识库

- **描述**：登录用户填写知识库名称和描述创建新知识库，用于存储和管理文档资料。
- **验收标准**：
  - 给定：用户已登录系统。
  - 当：用户填写知识库名称和描述并创建。
  - 那么：系统创建知识库并保存到数据库。
- **依赖关系**：无
- **估算工作量**：4故事点

### P0 - US-006：上传文档

- **描述**：用户创建知识库后上传TXT或Markdown格式文档，系统验证格式保存内容并处理，为智能体提供知识支持。
- **验收标准**：
  - 给定：用户已创建知识库。
  - 当：用户选择TXT或Markdown文件并上传。
  - 那么：系统验证文件格式，保存文档内容，并异步进行分块和向量化处理；如果文件格式不正确，系统提示错误信息。
- **依赖关系**：依赖于 US-005 创建知识库，需要先有知识库才能上传文档。
- **估算工作量**：3故事点

### P1 - US-007：查看知识库文档

- **描述**：用户访问知识库详情页面，查看知识库中所有文档的文件名、上传时间、处理状态等信息。
- **验收标准**：
  - 给定：用户已创建知识库且库中有上传的文档。
  - 当：用户访问知识库详情页面。
  - 那么：系统显示该知识库中的所有文档，包括文件名、上传时间、处理状态。
- **依赖关系**：依赖于 US-005 创建知识库和 US-006 上传文档，先创建知识库并上传文档后才能查看。
- **估算工作量**：3 故事点

## 三、工作流管理模块

### P1 - US-008：创建工作流

- **描述**：登录用户通过可视化编辑器创建工作流，配置节点和参数保存，系统验证格式并保存定义。
- **验收标准**：
  - 给定：用户已登录系统。
  - 当：用户在工作流编辑器中拖拽节点、连线、配置节点参数并保存。
  - 那么：系统验证工作流格式（DAG验证），保存工作流定义。
- **依赖关系**：无
- **估算工作量**：4 故事点

### P1 - US-009：执行工作流

- **描述**：用户创建工作流后输入参数执行，系统按顺序执行节点并返回结果。
- **验收标准**：
  - 给定：用户已创建工作流。
  - 当：用户输入工作流参数并执行。
  - 那么：系统按顺序执行节点，更新节点执行状态，最终返回执行结果。
- **依赖关系**：依赖于 US-008 创建工作流，创建后才能执行。
- **估算工作量**：4 故事点

### P1 - US-015：修改工作流

- **描述**：登录用户打开已创建的工作流，对节点、连线、参数等进行修改，完成后保存，系统验证修改后的工作流格式并更新定义。
- **验收标准**：
  - 给定：用户已登录系统且存在要修改的工作流。
  - 当：用户打开工作流进行修改操作，完成后点击保存按钮。
  - 那么：系统验证修改后的工作流格式（DAG验证），若验证通过则更新数据库中的工作流定义；若不通过，提示用户修改不符合要求。
- **依赖关系**：依赖于 US-008 创建工作流，先创建工作流才能进行修改。
- **估算工作量**：3故事点

### P1 - US-017：查看工作流列表

- **描述**：登录用户希望查看自己创建的所有工作流列表，通过访问系统提供的工作流列表页面，可看到每个工作流的名称、创建时间、状态（如已完成、进行中、未开始等）等信息，以便对工作流进行管理和操作。
- **验收标准**：
  - 给定：用户已登录系统。
  - 当：用户在系统界面中点击工作流列表页面的链接或按钮，访问该页面。
  - 那么：系统从数据库中查询该用户创建的所有工作流信息，并在页面上显示这些信息，包括工作流的名称、创建时间、状态等，同时页面加载时间应在合理范围内（如不超过3秒）。
- **依赖关系**：依赖于 US-008 创建工作流，只有先创建了工作流，才能查看工作流列表。
- **估算工作量**：2 故事点

### P1 - US-016：删除工作流

- **描述**：登录用户在工作流列表中选择要删除的工作流，确认删除操作后，系统将该工作流从数据库中移除。
- **验收标准**：
  - 给定：用户已登录系统且存在要删除的工作流。
  - 当：用户在工作流列表中选择工作流，点击删除按钮并确认删除操作。
  - 那么：系统验证用户权限，若有权限则将该工作流从数据库中删除，同时在工作流列表页面中刷新显示，移除已删除的工作流。
- **依赖关系**：依赖于 US-008 创建工作流和可能的查看工作流列表功能，先有创建和查看操作，才能进行删除。
- **估算工作量**：3 故事点

## 四、插件管理模块

### P1 - US-010：注册插件

- **描述**：登录用户填写插件信息并上传OpenAPI规范JSON文件注册插件，系统验证保存。
- **验收标准**：
  - 给定：用户已登录系统。
  - 当：用户填写插件名称、描述，上传符合OpenAPI规范的JSON文件并注册。
  - 那么：系统验证文件格式，保存插件信息。
- **依赖关系**：无
- **估算工作量**：3 故事点

### P1 - US-011：启用/禁用插件

- **描述**：用户对已注册插件进行启用或禁用操作，系统更新插件状态。
- **验收标准**：
  - 给定：用户已注册插件。
  - 当：用户在插件管理界面切换插件启用/禁用状态。
  - 那么：系统更新插件状态信息。
- **依赖关系**：依赖于 US-010 注册插件，先注册才能进行启用/禁用操作。
- **估算工作量**：2 故事点

## 五、综合功能

### P1 - US-012：发布智能体

- **描述**：用户将创建好且处于草稿状态的智能体发布，系统验证配置并更新状态。
- **验收标准**：
  - 给定：用户已创建处于草稿状态的智能体。
  - 当：用户点击发布按钮。
  - 那么：系统验证智能体配置，若完整则更新为已发布状态。
- **依赖关系**：依赖于 US-001 创建智能体，创建后才能发布。
- **估算工作量**：3 故事点

### P0 - US-013：智能体对话

- **描述**：用户与已发布的智能体进行对话，系统根据配置调用模型、检索知识库、执行工作流并返回回答。
- **验收标准**：
  - 给定：用户已发布智能体。
  - 当：用户输入问题并提交。
  - 那么：系统根据智能体配置生成回答并返回给用户。
- **依赖关系**：依赖于 US-012 发布智能体，发布后才能进行对话。
- **估算工作量**：4 故事点
